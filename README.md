# Baloot 450 — PHP Native

هذا الفرع هو نسخة PHP الأصلية للعبة بلوت 450، ويستخدم MySQL لحفظ الغرف واللاعبين والحسابات ونتائج المباريات.

## الحسابات والملف الشخصي
- التسجيل بالبريد وكلمة المرور مع تفعيل البريد الإلكتروني.
- تسجيل الدخول والخروج، مع جلسات آمنة في Cookies من نوع HttpOnly/Secure/SameSite.
- استعادة كلمة المرور عبر رابط لمرة واحدة صالح لمدة 30 دقيقة.
- ملف لاعب قابل للتعديل: اسم العرض، الصورة الرمزية، والنبذة.
- إحصائيات دائمة: مجموع النقاط، المباريات، الفوز، الخسارة، والتعادل.
- ترتبط هوية الحساب بمعرف الضيف المحفوظ حتى يستعيد اللاعب مقعده عند العودة.

## احتساب نقاط اللاعب
تُضاف إلى نقاط اللاعب نقاط فريقه النهائية في كل مباراة مكتملة. وتسجل نتيجة الفوز أو الخسارة أو التعادل مرة واحدة فقط لكل لاعب ومباراة، حتى لا تتكرر عند إعادة إرسال الطلب.

## ملفات قاعدة البيانات
- `database/schema.mysql.sql`: الجداول الأساسية للغرف واللاعبين والحركات.
- `database/migrations/002_accounts_profiles.sql`: جداول الحسابات والجلسات واستعادة كلمة المرور ونتائج المباريات.
- يجب تطبيق المخطط الأساسي ثم الترقية مرة واحدة على قاعدة المشروع الحالية؛ الترقية لا تحذف بيانات الغرف.

## إعداد الاستضافة
PHP 8.1+ مع `pdo_mysql` و`mbstring` وHTTPS مطلوب. اجعل Document Root يشير إلى `public/` فقط.
اضبط في PHP-FPM/Apache:
- `APP_ORIGIN=https://blout.arb.im`
- إعداد MySQL الموجود خارج المستودع في `/home/arbim/baloot450-config.php` بالمفاتيح `dsn`, `user`, `pass`, `origin`.
- أضف إلى المصفوفة نفسها `app_url` بقيمة `https://blout.arb.im` و`mail_from` بعنوان بريد صالح، أو عرّف `APP_URL` و`MAIL_FROM` في بيئة PHP-FPM/Apache.

## مسارات الحسابات
- `POST /api/auth.php?action=register`
- `GET /api/auth.php?action=verify&token=...`
- `POST /api/auth.php?action=login`
- `POST /api/auth.php?action=me`
- `POST /api/auth.php?action=logout`
- `POST /api/auth.php?action=forgot`
- `POST /api/auth.php?action=reset`
- `POST /api/auth.php?action=profile`

## تشغيل اللعبة
- لا يحتاج هذا الفرع إلى Node.js أو Socket.IO أو منفذ 3000.
- واجهة اللعب تستخدم `public/api-client.js` و`public/api/room.php`.
- محرك القواعد والشراء والقيد والبوتات تحت `app/Game/`.
- تخزين الغرف والحركات والحسابات في MySQL/InnoDB.
- شغّل `public/api/cron.php` عبر CWP Cron كل دقيقة لاستعادة المهل والمهام المؤجلة.

## الاختبار والنشر
شغّل اختبارات PHP وMySQL عبر GitHub Actions. نجاح الاختبارات لا يثبت إعداد البريد أو CWP؛ اختبر البريد فعلياً على بيئة staging قبل فتح التسجيل للعامة.
لا يتم النشر تلقائياً من هذا الفرع. راجع `DEPLOY_CWP.md` قبل رفع الملفات وتطبيق ترقية قاعدة البيانات.
